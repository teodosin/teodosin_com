Artpark

Autumn 2024

At my first job I got to work on an ecommerce site for traditional art. Artpark was the working title for it. I was working on it alone, so I had set the foundations for every part of the stack:

  • UI design in Figma
  • Frontend development in Typescript with Svelte
  • Backend development in Rust with Axum and GraphQL

The concept also included an AI to help the user find artworks using natural language, and to serve as a place to put flavour text on the artworks and articles.

The project was shelved after a few months, right before it was time to set up the initial database. I can’t show the code or the live site, but I can show the design exploration I did.
